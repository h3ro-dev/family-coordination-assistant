# Claude Design Handoff Prompt

You are reimagining the visual design of an existing founder-facing proposal page for Looheru.AI.

## Non-Negotiable Content Constraint

Do not change the content itself.

You may change:
- visual hierarchy
- layout
- section rhythm
- navigation
- typography
- spacing
- color system
- chart and workflow presentation
- page-to-page pacing
- responsive behavior
- supporting design motifs

You may not change:
- claims
- citations
- numbers
- prices
- equity ranges
- legal/compliance statements
- source labels
- roadmap phases
- section meaning
- headings unless only visually restyled

## What To Design

Create a premium, boardroom-ready proposal experience for a strategic partnership conversation. The current content is strong but should feel more bespoke, more confident, more modern, and less like a static slide dump.

The design should still support a serious founder/investor/operator conversation. It should not feel like a marketing landing page. It should feel like a high-end strategy deck translated into a web-native proposal.

## Desired Direction

Use a refined editorial strategy aesthetic:
- decisive information hierarchy
- strong section openers
- polished diagrams and workstream visualizations
- premium typography
- restrained but memorable color system
- quiet confidence, not startup gimmicks
- high readability for long strategic content
- clean citation treatment that supports trust without distracting
- mobile and desktop responsive structure

## Files Attached

- `proposal.html`: current HTML proposal content and structure.
- `proposal-content-outline.md`: extracted heading outline and content freeze reminder.
- screenshots if available: current rendered state for visual reference.

## Required Output

Return a complete redesign direction that can be implemented as HTML/CSS without changing the content:

1. Design concept summary.
2. Color palette with hex values.
3. Typography recommendation using web-safe or easily loaded fonts.
4. Layout system for desktop and mobile.
5. Section-by-section treatment notes.
6. Citation/source-chip treatment.
7. Workstream / roadmap visualization treatment.
8. Any CSS or HTML structure recommendations.
9. If possible, provide a downloadable HTML/CSS artifact or code block that preserves the existing content while replacing the presentation layer.

## Acceptance Criteria

The resulting design should:
- preserve content integrity
- improve executive readability
- make the A/B/C partnership options clearer
- make the roadmap and workstreams easier to scan
- make source/calc support feel credible, not cluttered
- avoid generic AI design patterns
- avoid purple-blue gradient hero aesthetics
- avoid a one-note palette
- avoid decorative cards nested inside cards
- keep text readable on mobile
